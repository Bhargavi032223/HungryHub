# HungryHub 🍔

HungryHub is a responsive food ordering website developed using HTML, CSS, JavaScript, and Bootstrap. The project focuses on creating a clean user interface and responsive design to provide a smooth browsing experience across devices.

## Features
- Responsive web design
- Interactive user interface
- Bootstrap-based layout
- Organized food menu sections
- Smooth navigation

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
